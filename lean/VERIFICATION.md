before starting any job, also on a trivial project), so the `lakefile.lean` was checked only by reading.
`scripts/build_direct.py` runs the same elaboration steps that Lake would (checker modules compiled to C and linked
into one shared library loaded with `--load-dynlib`; every other module elaborated in import order). If `lake build`
fails for you, please open an issue and use `scripts/build_direct.py`. Regeneration of the CNFs from scratch with the
`sat/` pipelines was not re-run for this release.
