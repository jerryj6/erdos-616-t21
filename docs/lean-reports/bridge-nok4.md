## Architecture
1. `bridge/TrCheck.lean` (core Lean only, compiled to a shared library and loaded with `--load-dynlib`):
   an executable re-implementation of tr_core.py: per-edge rules `edgeOk`, state enumeration `states`, universe `univ`
   (trace order = DIMACS variable order), pair rules `pairRules`/`pairOk`/`compat`, and a clause checker:
   every clause of a case CNF must be (i) the case unit `x_r`, (ii) a COV clause: with `B := full ∖ ⋃(its traces)`,
   `|B| ≤ 4`, `B` meets every base edge, and every universe trace avoiding `B` occurs in it, or (iii) a binary
   all-negative clause `¬x_i ∨ ¬x_j`, `i ≠ j`, with `compat univ[i] univ[j] = false` (no state pair, no overlap vector
   passes the pair rules). Plus `orbitOk`: the root 4-set B* is needed and every avoider of B* is mapped by a listed base
   automorphism `(g, π)` (re-checked: permutations, `P_q`-bits and `|O_q|` preserved) onto a case representative.
2. `bridge/TrRun.lean`: `native_decide` proofs that `checkAll` accepts the three classes (all case CNFs, the very
   `parseDimacs E616.<name>.cnfText` terms of the LRAT certificates).
3. `BridgeNoK4.lean` (Mathlib + E616Full + TrCheck): semantics. A `Base C H` (core points `core i`, base edges `P q ∈ H`
   with the class bit pattern, points in two base edges are core); trace/state of an edge; the assignment
   `x_i := ∃ non-base edge with trace univ[i]`; theorem: if every non-base edge passes `edgeOk` (EdgeSound) and every pair
   of distinct non-base edges passes `pairRules` at its TRUE overlap vector (PairSound), then the assignment satisfies every
   checked case CNF — contradicting `not_exists_sat`; symmetry via relabelling the Base (no permutation of V needed).
